# Canadian employers to test for an applicant tracking system board.

# This is a list of CANDIDATES, not a list of working boards. Nothing here is
# added to the registry until `python poller/cli.py hunt` has fetched it and
# seen real postings come back, which is the same rule the rest of the project
# follows: 24 hand written slugs were shipped once, all 24 were dead, and the
# fix was to stop trusting names that had never been fetched.
#
# The bias is deliberate. Discovery mines its slugs from SimplifyJobs, a US new
# grad aggregator, so the registry knows roughly 900 American boards and almost
# no Canadian ones. Big Canadian names are here, but so are a lot of companies
# between a hundred and three hundred people, because those are the ones no
# aggregator lists and the ones a search from outside Canada never surfaces.
#
# A name is tried as a slug on every platform whose board key is a company
# name. Lines starting with # are ignored.
